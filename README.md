# MozKhan — مدیریت و صندوق فروشگاه دخانیات

اپ اندروید (Kotlin + Jetpack Compose) با رابط کاملاً فارسی، راست‌به‌چپ، تاریخ شمسی و تم روشن/تیره.

## امکانات
- **فروش سریع**: اسکن بارکد (ML Kit) ← کارت تأیید ← افزودن به فاکتور. گزینهٔ «افزودن خودکار» در تنظیمات.
- **کالاهای بدون بارکد** (قهوه، ذغال، تنباکو…): تعریف به‌صورت **تعدادی** یا **وزنی** (قیمت هر کیلو، فروش به گرم)، دسترسی سریع از صفحهٔ فروش.
- **تشخیص تصویری**: هنگام تعریف کالا ۲–۳ عکس مرجع بگیرید (متن لاتین روی بسته هم برای پیشنهاد نام خوانده می‌شود). در فروش، با دکمهٔ «تشخیص تصویری» کالا شناسایی و پس از تأیید اضافه می‌شود. کاملاً آفلاین و کم‌مصرف (بدون مدل سنگین).
- **قیمت‌گذاری**: قیمت خرید/فروش، تعیین فروش با درصد سود، تغییر درصدی/عددی سریع، ویرایش گروهی قیمت.
- **موجودی دقیق**: موجودی = مجموع حرکت‌های انبار (خرید، فروش، ابطال، شمارش) ← هیچ‌وقت با سینک چند گوشی خراب نمی‌شود.
- **گزارش حرفه‌ای**: روز/هفته/ماه/سال شمسی؛ فروش، بهای تمام‌شده، سود ناخالص، حاشیه سود، هزینه‌ها، **سود خالص**، نمودار روند، پرفروش‌ها، فهرست و ابطال فاکتورها.
- **واحد پول**: تومان / ریال.
- **سینک چند گوشی با یک جیمیل** (Firebase Firestore + ورود Google) — اختیاری؛ بدون اینترنت هم کار می‌کند و پس از اتصال خودکار همگام می‌شود.
- پشتیبان‌گیری/بازیابی JSON.

## فعال‌سازی سینک Google (اختیاری)
1. در [Firebase Console](https://console.firebase.google.com) یک پروژه بسازید و اپ اندروید با پکیج `com.mozkhan.shop` اضافه کنید (SHA-1 کلید دیباگ را هم وارد کنید: `./gradlew signingReport`).
2. Authentication ← Sign-in method ← **Anonymous** را فعال کنید (برای «کد فروشگاه»؛ اگر با حساب Google وارد می‌شوید **Google** را هم فعال کنید).
3. Firestore Database را بسازید و این قوانین را بگذارید و Publish کنید:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    // پوشهٔ هر فروشگاه = کد فروشگاه (یا شناسهٔ حساب Google). همهٔ گوشی‌های واردشده با همان کد به آن دسترسی دارند.
    match /shops/{shop}/{doc=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```
   (قانون قدیمی `request.auth.uid == uid` با «کد فروشگاه» کار نمی‌کند، چون نام پوشه کد فروشگاه است نه شناسهٔ کاربر؛ نتیجه‌اش «دسترسی رد شد» است.)
   اگر خطایی در ارسال باشد، نقطهٔ وضعیت بالای صفحه قرمز می‌شود و متن خطا در تنظیمات دیده می‌شود. «آزمایش اتصال» تعداد کالا و فاکتورهای ابر و گوشی را مقایسه می‌کند.

   **نحوهٔ کار سینک (نسخهٔ ابری ۴):** هر تغییر همان لحظه در صف ارسالِ داخل دیتابیس ثبت می‌شود و تا وقتی سرور تأیید نکند پاک نمی‌شود (بدون اینترنت، بسته شدن برنامه یا قطع اتصال چیزی گم نمی‌شود). دریافت هم افزایشی است: هر بار فقط اسنادی خوانده می‌شوند که از آخرین بار تغییر کرده‌اند، پس سهمیهٔ رایگان Firebase تمام نمی‌شود. همهٔ گوشی‌ها باید نسخهٔ جدید را نصب کنند (گوشی با نسخهٔ قدیمی پیام «به‌روزرسانی کنید» می‌گیرد). «همگام‌سازی کامل» در تنظیمات همه‌چیز را یک بار با ابر مقایسه می‌کند.
4. `google-services.json` را در پوشهٔ `app/` بگذارید و دوباره بسازید. (بدون این فایل، اپ فقط محلی کار می‌کند.)
